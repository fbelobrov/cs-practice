Главное отличие между git diff, git show, git log, git log -S и git blame — в том, какую информацию об изменениях в проекте мы хотим получить.

git diff — что изменилось?

git show — что содержит конкретный коммит и какие изменения он внёс?

git log — какие коммиты были сделаны и в каком порядке?

git log -S — в каком коммите изменилось количество вхождений определённого текста?

git blame — какой коммит последним изменил каждую строку файла?
